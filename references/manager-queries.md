# Запросы менеджеров

## Только автомобиль

Запрос: «Подбери зимние шины на мой автомобиль».

Ожидаемый ответ: skill не проверяет совместимость с автомобилем, а `robotyre-stock/v1` не публикует типоразмер как структурированное поле. Можно уточнить поддерживаемые условия, например сезон и бюджет. Не проси VIN и не обращайся к внешнему сервису совместимости.

Запрос: «Что есть на этот автомобиль?».

Ожидаемый ответ: объясни границу совместимости и запроси только те условия поиска, которые публикует источник.

## Достаточный запрос

Запрос: «Найди летние шины, минимум четыре штуки, до 8 000 за единицу, доставка не дольше трёх дней».

Соответствие флагам:

| Условие | Флаг |
|---|---|
| шины | `--product-type Шины` |
| лето | `--season Лето` |
| минимум четыре единицы | `--min-total-quantity 4` |
| цена продажи до 8 000 | `--max-price 8000` |
| доставка до трёх дней | `--max-delivery-days 3` |

Сначала обнови кэш, затем выполни поиск с небольшими `--limit` и `--offers-limit`. В ответе сначала покажи свежесть и предупреждения, отдельно SKU и единицы, затем товары и предложения. Не скрывай `unknown` и `missing`.

## Недостаточные характеристики

Запрос: «Нужны диски, четыре штуки».

Ожидаемое уточнение: запроси характеристики, необходимые менеджеру для выбора, и не подставляй предполагаемые значения. Используй только подтверждённые условия, которые поддерживает `--help` CLI.

## Устаревший кэш

Если refresh вернул `stale_cache`, допустимо выполнить поиск по проверенному предыдущему поколению. Ответ начни с явного предупреждения, укажи `generated_at`, `checked_at` и все коды из `warnings`; не называй данные актуальными. `source_stale` может сочетаться с причиной fallback; не скрывай ни один код.

## Запрос с типоразмером

Если менеджер указал размер, не извлекай его из названия и не передавай `--size`. Объясни, что канонический источник не даёт такого фильтра. Ручной запуск с непустым `--size` завершится ошибкой `query_unsupported`.
